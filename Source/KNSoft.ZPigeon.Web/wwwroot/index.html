新实例创建独立身份；更新已有实例保留其 CNG 密钥和公钥指纹。同一电脑需要两个客户端时，分别生成两个新实例。

传输方式

TCP 使用 TLS，UDP 使用 DTLS 1.2，QUIC 必须使用 TLS 1.3。依次尝试所选方式，同一实例只保持一条活动连接。

连接目标固定为本机 127.0.0.1，QUIC 与 TCP 默认使用端口 21943，UDP 默认使用端口 21944。私钥在目标机器首次运行时由当前用户 CNG 创建，EXE 只包含服务端根证书公钥。
